# Jeevan Raksha Pharmacy – MySQL Mini Project

## Project Overview
Jeevan Raksha Pharmacy is a MySQL database management mini-project designed to manage pharmacy-related information such as customers, suppliers, medicines, and orders.

## Features
- Manage customer and supplier information
- Store medicine details, stock, price, category, and expiry date
- Manage customer orders and order items
- Use primary and foreign keys to establish relationships
- Perform data retrieval, filtering, aggregation, and analysis using SQL queries
- Identify high-value orders, best-selling medicines, high-spending customers, and low-stock medicines

## Tech Stack
- MySQL
- SQL
- MySQL Workbench

## Database Structure
The database contains five main tables:
- Customers
- Suppliers
- Medicines
- Orders
- Order_Items

## Setup and Run
1. Install MySQL and MySQL Workbench.
2. Open MySQL Workbench.
3. Create a new database for the project.
4. Run the SQL commands provided in the project document.
5. Insert the sample data.
6. Execute the SQL queries to verify the database operations.

## Environment Variables
No environment variables are required for this MySQL database project.

## API / Database Notes
This project does not use an API or external application. It is a relational MySQL database project. The database uses primary keys and foreign keys to maintain relationships between tables.
